# Roadmap to v1.0.0

There are a couple of feature ideas that are planned.
The following features should be implemented or planned
without breaking changes.

## about:blank

- an `about:blank` fallback problem type if the given error is not registered

## Optional Overview Page

- an optional page at the root of the problem type definition pages,
which contains an index of all registered problem types

## Custom Error Handling

- allow injection of a callback hook for custom error handling

## Custom Scheme

- allow for specific overrides of some styles used for problem type definition pages

## Custom Styles

- allow complete override of the styles used for problem type definition pages

## Custom Renderers

- allow completely custom renderer implementations for problem type definition pages

## Localization

Localization of
- the problem detail responses
- the provided problem type definition pages
